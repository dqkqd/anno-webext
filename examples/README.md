# anno-webext examples

This sub directory contains some examples using the `anno-webext` library.
All of the extensions can be run using `npm run web-ext:chrome` or `npm run web-ext:firefox`
(depends on which browser you are using).

| directory                  | description                                                |
| -------------------------- | ---------------------------------------------------------- |
| [basic](./basic/README.md) | The dead simple extensions using the `anno-webext` library |
